接続先と API キー（任意）

キーの値ではなく、キーを入れた環境変数の名前（例: OPENAI_API_KEY）を入力します。値は保存も表示もされません。リモートの接続先 URL は gateway-config.json でのみ設定できます。

接続テストは短いリクエストを 1 回だけ送ります（出力は数トークン、一定時間で打ち切り）。ローカルは無課金、API プロバイダではごく少額の課金が発生することがあります。

小さいモデル向けのプロファイル

小さいコンテキストのモデル向けに、記憶の量と送るツール定義を絞ります。この画面では変更できません: gateway-config.json の context_profile（default / small / tiny）か環境変数 STIRA_CONTEXT_PROFILE を使い、再起動で反映します。既定: default（変更なし）。

処理ごとのモデル

    要約などの補助の処理が使うモデルです。既定はすべて会話と同じモデル（inherit）。この画面では変更できません: gateway-config.json の task_models か環境変数 STIRA_TASK_MODEL_<処理名> を使い、再起動で反映します。指定したモデルが使えないときは別のモデルに切り替えず、その処理を失敗にします。

    安全（ブレーカー・ツール）

    エージェントが不安定になったときに書き込み・実行系を制限する仕組み（ブレーカー）と、使ってよいツールを決めます。応答はブレーカーでは止まりません。

    安全プリセット

    ツールの許可とブレーカーをまとめて切り替えます。選ぶと変更点が表示され、「下書きに反映」→「保存」で確定します。実行系ツールはどのプリセットでも無効のままです。

        ツールの許可

        エージェントが使ってよいツールを選びます。ブレーカーが「警告」以上のときは、ここで許可していても書き込み・実行系は止まるか、1 回ごとに人の承認が必要になります。

        ツールごとに「常に許可」「毎回確認」「使わない」を選びます。実効の判定は、ここでの選択・ブレーカー・保護（床）のうち最も厳しいものです。緩める変更は確認が必要で、ブレーカー作動中はできません。

        「毎回確認」のツールの承認要求は、チャットと「承認」ページに届きます

        {% endif %}

        「常に許可」にしたツールの永続許可（全ツール共通）— 範囲: そのツールの全引数 / 期限: 取り消すまで（自動失効なし） / 取消先: この一覧でそのツールを「毎回確認」か「使わない」に変えて保存。ブレーカーと床は引き続き適用されます。

        「隔離」はツールが OS の隔離環境で動くかどうかで、承認とは別です。承認してもツールは隔離されません。

        YOLO は「毎回確認」のツールだけを自動で承認します。「常に許可」は元から確認が出ず、「使わない」は YOLO の間も実行されません。

        目的別のプロファイル

                    書き込みできる場所

                    ファイル書き込みツール（file_write / editor）が書き込める場所です。ここに含まれない場所への書き込みは拒否されます。SOUL や手続き記憶などの保護対象は、どの設定でも書き込めません。

                    範囲

                    詳細

                    保存先: agent-config.json の write_roots（既定 ["@workspace"]）。@workspace は workspace_dir、未設定ならチャットサーバーのデータディレクトリです。範囲外への書き込みは拒否されます（write_outside_action = deny）。チャットサーバーの再起動で反映されます。

                    読み取りできる場所

                    ファイルを読むツール（file_read / view_image / image_reader / editor の view / lsp_*）が読める場所です。ここに含まれない場所は読めません（E_READ_OUTSIDE_ROOTS）。鍵・認証情報・キーチェーン・ブラウザのプロファイル（~/.ssh、~/.aws、.env、*.pem など）は、どの設定でも読めません（E_READ_SECRET_PATH）。

                    範囲

                    詳細

                    隔離の段階（観測のみ）

                    ゲートがすでに出している拒否と保留（秘密パスの読み取り、床への書込み、自分のダッシュボードへの呼び出し、外部送信の保留、連続実行）を数え、仮に段階が上がるとしたらどこかを記録します。フェーズ 0 では何も止めません。

                    詳細

                    設定: agent-config.json の containment（{"phase": 0} で ON、無しで OFF）。環境変数 STIRA_CONTAINMENT_OBSERVE=0 で強制 OFF。チャットサーバーの再起動で反映されます。週次の集計は containment_cli の summary で出せます。

                    信頼ラベル（観測のみ）

                    ターンごとに文脈の信頼（trusted / untrusted）と機微（sensitive）を記録し、外部送信の呼び出しのうち、仮に送信の層があったら人に確認していたものを数えます。フェーズ 0 では何も止めず、プロンプトもツール結果も変えません。

                    詳細

                    設定: agent-config.json の taint（{"phase": 0} で ON、無しで OFF）。環境変数 STIRA_TAINT_OBSERVE=0 で強制 OFF。チャットサーバーの再起動で反映されます。週次の集計は taint_cli の summary で出せます。

                    YOLO（一時的な自動承認）

                    チャットの YOLO ボタンを押して確認すると、最大 6 時間、「毎回確認」のツールを自動で承認できるようになります。ここでは「どこまで許すか」と上限を決めます。ここで許可しても自動承認は始まりません。「使わない」・保護（床）・ブレーカーはどの設定でも変わりません。
