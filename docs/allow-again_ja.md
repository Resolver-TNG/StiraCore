# 承認カードの「継続許可」(ADR 0025)

[English](allow-again.md) · 設計: [ADR 0025](adr/0025-allow-again-from-the-approval-card.md) ·
承認: [hitl-approvals.md](hitl-approvals.md)

ツールの規則が **Ask(毎回確認)** だと、呼び出しのたびに承認カードが出ます。エージェントが同じフォルダの
ファイルを 5 つ編集すれば「今回のみ承認」も 5 回です。そこで承認カードには、ボタンがあと 2 つあります
(既定で表示されます。設定は要りません)。

| ボタン | すること | 期間 |
|---|---|---|
| **承認して、このセッション中は同じ操作を許可** | この呼び出しを承認し、以後の **同じツール・同じ対象** の呼び出しを自動で承認します | 会話が終わるまで、**最長 2 時間** |
| **承認して、このツールを『常に許可』に変更** | この呼び出しを承認し、実行が終わったらダイアログで設定ハブからそのツールを **常に許可** に保存できます(確認としてツール名を入力、変更は履歴に残り、元に戻せます) | 恒久(戻すまで) |

## 「同じ」とは

ボタンの下に対象が出ます(例: `file_write · projects/game/ 配下 · 最長2時間`)。

- `file_write`・`editor`(書き込み): **承認したファイルのフォルダとその下すべて**(書き込みルートより
  広くはなりません)。ワークスペース直下のファイルなら「ワークスペース全体」と表示されます。
- `web_fetch`・`rss`: **同じホスト**。`http_request`: 同じホストへの **GET / HEAD だけ**。
- `memory_write`: 同じ層(episodic)。記憶の読み取り・`journal`・`current_time`・検索: そのツール。

別のツール・別のフォルダ・別のホストへの呼び出しでは、もう一度カードが出ます。ファイルは開く時点で
もう一度確かめるので、途中でフォルダを別の場所へのリンクに差し替えても書き込みは拒否されます。

## 出ないとき

「今回のみ承認」と「拒否」だけになり、理由が 1 行出ます(「この操作は毎回確認します(…)」)。対象は、
実行系ツール(`shell`・`batch` など)、MCP・分類できないツール、パスの **読み取り**(`file_read`・
`editor view` など)、データを送る操作(`webhook_send`、POST)、秘密らしき引数、ワークスペースの外、
編集した呼び出し、再起動後に復元したカード、ブレーカーが NORMAL でないときです。Never・保護された
場所・ブレーカーの書き込みブロック・CRITICAL は継続許可より先に判定されるので、継続許可で回避される
ことはありません。

## 確認と終了

チャットのヘッダーとステージの会話枠のふち(YOLO バッジの隣)に **「継続許可 N件」** が出ます。押すと一覧が
開き、各継続許可のツール・対象・残り時間・使用回数が表示されます。行ごとの **取り消し** と、最後の
**すべて取り消し** もあります。自動で承認されるたびに、チャットのログに `↻ 継続許可で承認: file_write · projects/game/ 配下`
と 1 行出ます。次のどれかで自動的に終わります。

- 停止(チャットの ■、YOLO の停止、「すべて取り消し」)
- `/new`
- ブレーカーが NORMAL でなくなったとき
- ツール規則・ルートを保存したとき
- 2 時間の経過
- サーバーの再起動(メモリにしか持たないため)

押した操作・自動承認・終了はすべて監査ログ(`audit.allow.*`・`audit.tool.*`、フォルダとホストは鍵付き
ハッシュだけ)に残ります。監査ログに書けないときは何も自動承認せず、再起動までボタンも出ません。

## YOLO との違い

| | 継続許可 | YOLO([yolo-quickstart_ja.md](yolo-quickstart_ja.md)) |
|---|---|---|
| 始め方 | 1 枚のカードで押す(いつでも使えます) | 「YOLO を開始」ボタンと確認(既定で表示。`STIRA_YOLO_ALLOW=off` で非表示) |
| 範囲 | **1 つのツール × 1 つの対象**(フォルダ・ホスト) | 階層内のすべての Ask ツール |
| 期間 | 会話の間、最長 **2 時間** | **6 時間**(ブレーカーで一時停止) |
| 実行系 | 対象外 | 「実行系を含める」を選んだときだけ |

両方あるときは YOLO が先に答えます。継続許可が YOLO の窓を開く・延ばす・上限に数えられることはありません。
